# IoT: SIGNAL ZERO

Fondasi proyek untuk game browser edukasi IoT berbasis Vanilla JavaScript.

## Menjalankan

Buka `index.html` di peramban web modern. Tidak ada proses build atau dependensi tambahan.

STEP 1 -- Project Foundation, STEP 2 -- Main UI, STEP 3 -- Game Content, STEP 4 -- Core Quiz Engine, STEP 5 -- HP & Timer, STEP 6 -- Progress & HUD, STEP 7 -- Story, Dialogue & Quest, dan STEP 8 -- Exploration Minimal telah selesai.
